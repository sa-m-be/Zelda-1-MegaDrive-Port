# Frequently asked questions / Perguntas frequentes

### Is this a NES emulator?
No. The project aims to run the adapted game logic natively on Mega Drive / Genesis hardware, using the target platform's architecture.

### Is the game finished?
The MD22 development milestone is experimental. Full playthroughs, both quests and save behavior have not been certified. Initial real-hardware testing has been reported.

### Does it run at 60 fps?
60 fps is the performance target, not a verified benchmark. Region, scene and implementation may affect timing.

### Does it work on original hardware or flash cartridges?
Yes, the project developer reports testing on a Japanese Mega Drive Model 1 (NTSC-J) with an EverDrive V3 Pro flash cartridge. The exact tested build and scope have not been specified. Other configurations are not yet verified. Please report the exact console revision, region, cartridge, firmware and build when testing authorized releases.

### Where can I download the ROM?
This documentation package contains no ROM. Any future distribution must be reviewed for rights and accompanied by specific instructions.

### How do I apply a patch or build it?
Follow the instructions for the specific release. The current [build guide](BUILD.md) is provisional until the actual build tools and supported input checksums are verified.

### Why are some sound effects quieter?
Sword and damage sound effects were reported present but quiet in recent revisions. Audio mixing is a remaining development task.

### Can I contribute?
Yes, by reporting reproducible bugs, suggesting technical improvements and submitting contributions to material that can lawfully be shared. See [CONTRIBUTING.md](CONTRIBUTING.md).
